    RuninqVic 도움말

    1. 간편만들기

    1. 사진·동영상 추가로 사진이나 짧은 동영상을 넣습니다. 폴더에서 화면으로 끌어다 놓아도 됩니다. 동영상은 자막 탭에서 시작·끝 구간을 잘라 길이를 정합니다.
    2. 배경음악을 넣습니다. 여러 곡을 넣으면 순서대로 이어집니다. 음악 파일이 없으면 AI 버튼에 가사와 분위기를 적어 새 곡을 만들 수 있습니다(Mureka·ElevenLabs 등 작곡 서비스의 API 키 필요).
    3. 재생시간을 정합니다. 음악 재생시간에 균등하게 맞춤을 켜면 음악 길이에 맞춰 사진 시간을 자동 배분하고, 비트에 맞춰를 켜면 박자에 맞춰 장면이 바뀝니다.
    4. 오프닝·엔딩 제목을 확인합니다.

    2. 상세꾸미기

    타임라인에서 화면을 고른 뒤 자막, 디자인(배경·액자), 효과(전환·시네마틱)를 넣습니다. 전체적용을 누르면 모든 화면에 같은 설정이 적용됩니다.

    3. 동영상 만들기

    오른쪽 위 동영상 만들기를 누르고 크기·품질을 고르면 MP4(H.264/AAC) 파일이 만들어집니다. 1080p · 4K · 60fps · 세로(9:16) 쇼츠도 지원합니다.
