# RuninqVic 설계 문서 (2026-09-16)

## 목적
서비스가 종료된 **알씨 동영상 만들기**를 대체한다. 사진 여러 장 + 배경음악만 넣으면
재생시간을 자동 배분해 MP4 슬라이드쇼를 만들어 주는 프로그램. 원본의 워크플로
(간편만들기 4단계 → 상세꾸미기 자막/디자인/효과 → 만들기)를 그대로 계승하되,
원본에 없던 기능(비트 싱크, 세로/정사각 비율, 4K/60fps, 자동 저장, 프로젝트 파일)을 더한다.

## 사용자 / 제약
- 한국어 사용자, 비개발자. 설치·빌드 없이 더블클릭으로 실행돼야 한다.
- Windows 11, Edge/Chrome 설치되어 있음. 인터넷 없이도 동작해야 한다.
- 별도 서버, 계정, 외부 API 없음. 사진은 PC 밖으로 나가지 않는다.

## 접근 방식 비교
1. **브라우저 앱 (HTML/JS, WebCodecs + mp4-muxer)** — 선택
   - 장점: 설치 불필요, file:// 로 바로 실행, Edge `--app` 모드로 창 하나짜리 앱처럼 보임,
     GPU 가속 H.264 인코딩(WebCodecs), 자동 테스트/검증이 쉬움.
   - 단점: Edge/Chrome 필요(IE/Firefox 불가). AAC 인코더 미지원 환경은 WebM 폴백.
2. Python + PySide6 + FFmpeg — 진짜 네이티브지만 Python/FFmpeg 설치와 배포 패키징 필요, UI 검증 어려움.
3. Electron + FFmpeg — 200MB 배포본, 빌드 파이프라인 필요. 1안 위에 나중에 씌울 수 있음.

## 아키텍처 (빌드 도구 없음, 전역 네임스페이스 `RV`)
```
RuninqVic/
  index.html            UI 골격
  RuninqVic.bat         Edge/Chrome --app 모드로 실행하는 런처
  css/app.css           다크 테마, 주황 액센트
  js/state.js           프로젝트 모델, 기본값, 결정적 난수(Ken Burns 파라미터)
  js/timeline.js        슬라이드 시작/끝, 전환 겹침, 음악 맞춤, 비트 싱크 계산 (순수 함수)
  js/designs.js         배경/액자/시네마틱/전환 프리셋 (그리기 함수)
  js/render.js          Renderer: 시간 t → 캔버스 프레임 (미리보기·내보내기 공용)
  js/audio.js           음악 디코드, 오프라인 믹스(페이드/루프), 비트 검출
  js/exporter.js        WebCodecs(VideoEncoder/AudioEncoder) + mp4-muxer/webm-muxer
  js/store.js           IndexedDB 자동 저장, .rvproj 저장/열기
  js/app.js             UI 바인딩, 플레이어, 타임라인 DnD
  lib/mp4-muxer.min.js, lib/webm-muxer.min.js  (벤더링)
```
- **데이터 흐름**: UI 이벤트 → `RV.project` 수정 → `RV.timeline.compute()` → Renderer 다시 그림 → 자동 저장(디바운스).
- **미리보기와 내보내기는 같은 `Renderer.draw(t)`** 를 쓴다. 해상도만 다르다. 파티클/Ken Burns 는 시드 기반 결정적이라 미리보기=결과물.

## 기능 (원본 대비)
| 영역 | 알씨 | RuninqVic |
|---|---|---|
| 사진 추가 | 버튼/드래그 | 버튼/드래그/폴더, EXIF 회전 자동, 이름·날짜 정렬, 섞기 |
| 배경음악 | 1곡 | 여러 곡 순차, 시작점 자르기, 페이드 인/아웃, 루프, 볼륨 |
| 재생시간 | 장당 N초 / 음악에 균등 | + 장별 개별, **비트에 맞춰 자동 컷** |
| 화면비율 | 16:9, 4:3 | 16:9, 4:3, 1:1, **9:16(쇼츠/릴스)** |
| 사진위치 | 맞춤/채움, 여백 블러 | 맞춤/채움/원본, 블러 강도·어둡기 |
| 이동과 확대축소 | on/off | on/off + 강도, 장별 방향 결정적 |
| 오프닝/엔딩 | 텍스트 | 제목+부제, 스타일(클래식/시네마틱/미니멀), 길이 |
| 자막 | 글꼴/크기/색/위치/효과 3종 | + 굵게/기울임/그림자/외곽선/배경상자, 효과 5종, 전체 적용 |
| 디자인 | 배경(다운로드), 액자 | 배경 16종 내장(단색/그라데이션/질감/사용자색), 액자 10종 내장 |
| 효과 | 전환 다수, 시네마틱 8종 | 전환 12종+랜덤, 길이 조절, 시네마틱 7종 |
| 저장 | mp4, 용도/크기/품질 | mp4(H.264+AAC) 720p/1080p/1440p/4K, 30/60fps, 품질 3단+비트레이트, 진행률/취소/ETA |
| 프로젝트 | 없음 | 자동 저장(IndexedDB), .rvproj 파일 저장/열기 |

## 타임라인 수학
- 슬라이드 i 길이 d_i, i→i+1 전환 길이 tr_i (≤ 0.5·min(d_i, d_{i+1})).
- start_{i+1} = start_i + d_i − tr_i, 전체 = Σd − Σtr.
- 음악 맞춤: k = (L + Σtr) / Σd 로 d 를 일괄 스케일(최소 0.5초).
- 비트 싱크: 온셋 에너지 → 피크 → 이상 경계(i·L/N)에 가장 가까운 비트로 스냅, 최소 간격 0.7초.

## 오류 처리
- 지원 안 되는 파일: 건너뛰고 토스트로 알림. 디코드 실패 음악도 동일.
- WebCodecs 없음/H.264 미지원: VP9+Opus WebM 폴백, 그것도 없으면 내보내기 버튼 비활성 + 안내.
- AAC 미지원: WebM 폴백. 내보내기 중 취소 가능, 부분 파일은 버림.
- 저장 위치 선택 API 없으면 다운로드 폴백.

## 테스트
- `tests/` 없음 대신 `js/timeline.js` 는 순수 함수라 Node 로 단위 검증(`node tests/timeline.test.js`).
- 브라우저 E2E: 생성한 테스트 사진 6장 + 합성 음악으로 실제 MP4 내보내기까지 자동 확인.
